# 📊 Employee Productivity Prediction

A Machine Learning project that predicts employee productivity based on employee characteristics, work-related factors, and workplace conditions.

The project follows an end-to-end Machine Learning workflow, including data analysis, preprocessing, model training, hyperparameter tuning, model evaluation, and deployment using Streamlit.

---

## 🎯 Project Objective

The objective of this project is to build a Machine Learning model that can predict an employee's productivity score from relevant employee and work-related features.

The model can help organizations understand productivity patterns and provide data-driven insights for workforce management.

---

## 📌 Features Used

The model uses the following features:

- `age`
- `experience_years`
- `education_level`
- `technical_skill_score`
- `communication_score`
- `certifications_count`
- `avg_daily_focus_hours`
- `remote_work_ratio`
- `sleep_hours`
- `stress_level`
- `project_complexity`
- `team_size`
- `manager_rating`
